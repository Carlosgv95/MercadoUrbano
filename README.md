# 🛒 MercadoUrbano

MercadoUrbano es un proyecto de e-commerce fullstack desarrollado como parte de la certificación **Full Stack Developer**.  
El objetivo es crear una plataforma moderna, escalable y fácil de usar para la compra y venta de productos.

---

## 🚀 Tecnologías utilizadas

### Frontend
- **React** con Context API para manejo de estado global.
- **Bootstrap** para estilos responsivos.
- Componentes principales: `Navbar`, `Productos`, `Carrito`, `Registro`, `Header`, `ProductSlider`.

### Backend
- **Node.js** y **Express** para la API REST.
- **PostgreSQL** como base de datos relacional.
- **JWT** para autenticación segura.
- **CORS** habilitado para comunicación entre frontend y backend.
- **Supertest** para pruebas automatizadas.
